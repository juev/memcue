# "Quarrel is 3x faster than Brindle" — Quarrel Inc. engineering blog

We published 10 million 1 KB messages through Quarrel 1.4 and Brindle 3.2 on our own c7-metal test rig.
Quarrel reached 3.1 million messages per second, Brindle 1.0 million.

Method notes: one run per library, default settings, the Brindle WAL interval left at its default. The rig and the
harness are not public.
